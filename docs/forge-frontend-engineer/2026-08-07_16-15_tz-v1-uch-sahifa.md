## Arxitektura qарорlari

### Sana oralig'i oy-bazali API ustida

TZ ixtiyoriy `с … по …` oralig'ini so'raydi, API esa faqat `detail_month=Y-m`
qabul qiladi. `App\Support\Period` oraliqni oylarga bo'ladi,
`App\Support\BillingHistory` har bir oyni so'rab, natijalarni birlashtiradi va
kunlar bo'yicha qirqadi.

Cheklov: **12 oy** (`Period::MAX_MONTHS`). Har bir oy ~250 ms HTTP so'rov;
cheklovsiz oraliq PHP worker'ni bir daqiqaga band qilardi. Qirqilgan oraliq
UI'da ochiq aytiladi, jimgina qisqartirilmaydi.

Bir oy tushib qolsa (API xatosi) — o'sha oy o'tkazib yuboriladi va
"Ba'zi oylar uchun ma'lumot olinmadi" yozuvi chiqadi. Butun oraliqni 502 qilish
abonent uchun yomonroq.

### Noma'lum API maydonlari bitta joyda

`App\Support\AbonentProfile` — TZ so'ragan, lekin API'da bor-yo'qligi noma'lum
4 ta maydon (shartnoma №, keyingi tarif va narxi, joriy tarif narxi, keyingi
hisobdan yechish sanasi) shu yerda nomzod kalitlar ro'yxati orqali qidiriladi.
Topilmasa `null` qaytadi va UI "Нет данных" ko'rsatadi — soxta qiymat emas.

Billing maydon nomini aytgach, o'sha ro'yxatga bitta qator qo'shiladi va butun
dashboard yonadi. Boshqa hech qayerga tegish kerak emas.

### Har bir sahifa faqat o'zi ko'rsatadigan ma'lumotni so'raydi

`/statistics` to'lovlarni umuman so'ramaydi, `/finance` esa trafikni. Bitta
sahifa bo'lganda har bir yuklanish barcha bloklar uchun API'ga borardi.

### AJAX — HTML almashtirish, JSON emas

Davr tanlash formasi (`data-ajax-form`) → server blokning **Blade markup'ini** qaytaradi → brauzer
`innerHTML` bilan almashtiradi va jadvallarni qayta ulaydi. Shablon bitta
joyda qoladi (birinchi render ham, yangilanish ham bir xil `.blade.php`),
JSON→DOM qatlami umuman yo'q. JS ishlamasa forma oddiy POST qilib, o'sha
blokni qaytaradi.

### Jadvallar

`resources/js/modules/table.js` — saralash (`data-sort` + `data-value` sort
kaliti), qidiruv, pagination, CSV eksport. DataTables/jQuery yo'q.

Mobil (`< 640px`): `u-table-cards` jadvalni kartochkalarga aylantiradi, har bir
katakcha `data-label` orqali o'z sarlavhasini chiqaradi (TZ §11).

## Yo'l-yo'lakay tuzatilgan nuqsonlar

1. **Mobilda jadval kartochkaga aylanmasdi** — `min-w-[34rem]` utilitasi
   `u-table-cards` ning `min-width:0` qoidasidan ustun edi. `sm:min-w-[…]` ga
   o'zgartirildi.
2. **Atribut ichida escape qilinmagan `@lang()`** — 12 joyda `{{ __() }}` ga.
3. **CSV formula injection** — `payment_system` API'dan erkin matn; `=`, `+`,
   `-`, `@` bilan boshlanadigan qiymat Excel'da formula bo'lib ishlab ketardi.
   Apostrof bilan neytrallanadi.
4. **Qidiruv ikonkasi** grafik ikonkasi edi.

## Noto'g'ri "nuqson" (yozib qo'yildi, chalg'itmasin)

Excel eksportida BOM yo'qdek ko'rindi — aslida `Blob.text()` UTF-8 dekoderi
BOM'ni spetsifikatsiya bo'yicha o'zi olib tashlaydi. Xom baytlarda
(`arrayBuffer`) BOM joyida. Kodda nuqson yo'q edi; `﻿` escape'i baribir
literal belgidan ishonchliroq, shuning uchun qoldirildi.

Shuningdek: preview HTML build'dan keyin qayta render qilinmasa eski bundle
hashiga ishora qiladi va JS umuman yuklanmaydi — bu harness xatosi, mahsulot
emas. Kelgusi passlarda `npm run build` dan keyin preview'ni **doim** qayta
render qilish kerak.
